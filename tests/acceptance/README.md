# Сквозная проверка

Скрипт проверяет уже запущенный локальный стенд без изменения данных:

- доступность API и веб-интерфейса
- полный каталог и все 29 обязательных строк
- отсутствие нулевой подстановки вместо неизвестной цены
- точный заголовок CSV
- ежедневное расписание `Europe/Moscow`
- завершённое задание и сохранение успешных наблюдений при частичном сбое

Запуск после импорта каталога:

```powershell
node tests/acceptance/api-smoke.mjs --job <UUID задания>
```

Для проверки сохранности истории выполнить команду, перезапустить только `api`, `collector` и `web`, затем выполнить ту же команду с тем же UUID. Поля `succeeded`, `failed` и `observations` должны остаться неизменными.

Если состав исследовательского реестра намеренно изменён, ожидаемое число точных предложений можно передать явно:

```powershell
node tests/acceptance/api-smoke.mjs --exact-offers 62
```
