# Результаты автоматического сбора

Актуальный контрольный запуск выполнен 1 ноября 2026 года на полном наборе обязательных моделей.

Идентификатор задания `0fb553ef-9ab6-4286-a1d7-fc99eab04e7c`.

## Что работает

- сбор запускается кнопкой в интерфейсе и автоматически каждый день в 03:00 по `Europe/Moscow`
- ручное подтверждение для штатного запуска не требуется
- каждый источник обрабатывается отдельно, поэтому сбой одного сайта не останавливает остальные
- результаты сохраняются как неизменяемая история наблюдений
- отсутствующая или сомнительная цена не подменяется нулём
- точность модели проверяется по обозначению и критичным характеристикам, включая напряжение, диапазон колёс, скорость, лазер и комплектацию
- комплект `NORDBERG 4641N + VT-64` автоматически считается только из двух карточек одного продавца
- при сетевой ошибке обычного запроса система один раз пробует открыть страницу в браузере
- браузерный режим не используется для обхода CAPTCHA, ограничения частоты запросов или проверки человека
- для защищённых или нестабильных сайтов используются заранее проверенные точные резервные карточки
- таблица показывает каждого конкурента отдельной карточкой с ценой, разницей, датой и ссылкой. Источники-кандидаты и сомнительные цены тоже видны, но явно помечены и не входят в итоговое сравнение

## Почему сбор завершился частично

Статус `partial_success` означает, что отдельные источники не ответили надёжно. Это не означает потерю всех результатов задания.

### Неуспешные источники

- четыре официальные страницы `nordberg.ru` не открылись ни обычным запросом, ни через браузер до окончания ограниченного времени ожидания
- для `4523`, `46TRK(B)` и `46TRKE(B)` успешно сработали точные резервные карточки `optima-trade.ru`
- для `NORDBERG STANDART` безопасной конкурентной замены нет, потому что найденная карточка дилера расходится по внутренней высоте камеры
- официальная карточка `rossvik.moscow` для `VT-63` временно не открылась до окончания ограниченного времени ожидания; последнее надёжное наблюдение осталось в истории
- страница `tmktools.ru` для `46TRKE56(B)` больше не показывает открытую цену и предлагает авторизоваться
- для `46TRKE56(B)` успешно сработала точная резервная карточка `carmod.ru`

### Источники, пропущенные без обхода защиты

Три страницы `rustehnika.ru` вернули проверку пользователя. Система распознала защитную страницу, не пыталась решать CAPTCHA и не приняла её текст за товарную карточку.

- `NORDBERG 45TRKE` получен через `optima-trade.ru`
- `NORDBERG 4523N1(B)` получен через `optima-trade.ru`
- `NORDBERG 4638N(B)` получен через `autoservice2.ru`

## Почему конкурентная цена есть не для всех 29 моделей

После второго прохода пять моделей остаются нерешёнными из-за конфликта характеристик, поколения или комплектации. Их найденные карточки сохранены со статусом `требует проверки`, но намеренно не влияют на сравнение.

- `ES-26D`
- `4523PA1(B)`
- `Guangli GL2`
- `Guangli GL3 LUX`
- `Guangli GL10`

Автоматически принять их цены означало бы нарушить требование точного соответствия модели. Шестая позиция без текущего полноценного сравнения — `NORDBERG STANDART`, для которой точный официальный источник временно недоступен, а резервный конфликтует по характеристикам.

## Ограничения

- CAPTCHA и проверки человека не обходятся
- сайт может изменить разметку или скрыть цену после авторизации, поэтому отдельный адаптер может потребовать обновления
- полный запуск занимает несколько минут, потому что недоступные страницы проходят ограниченные повторы и браузерную проверку
- последняя надёжная цена остаётся в append-only истории, даже если источник временно упал в следующем запуске. В интерфейсе нужно учитывать дату наблюдения
- регион расчёта — Москва. Доставка, монтаж и дополнительные работы не включаются, если они явно не входят в опубликованную цену
- система не доказывает наличие товара на складе, если сайт сам не публикует однозначный статус
- 100 процентов конкурентного покрытия нельзя получить безопасно без паспортов или подтверждения конфигурации для пяти спорных моделей и точного доступного источника для `NORDBERG STANDART`
