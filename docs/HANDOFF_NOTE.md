# Записка по передаче решения

## Что передаётся

Рабочий прототип ежедневно собирает цены по 29 обязательным позициям, хранит неизменяемую историю, показывает подтверждённые и сомнительные конкурентные цены раздельно и выгружает CSV требуемого формата. Сбор запускается кнопкой и автоматически в 03:00 по Москве.

Стек соответствует заданию. Используются PostgreSQL 18, Python 3.13 и Playwright, NestJS 12, Prisma 7, React 18.3, TypeScript 5.9, Vite и Docker Compose. Дополнительных очередей и runtime ИИ нет.

## Фактический результат

- 267 товаров в каталоге
- 29 обязательных позиций
- 28 собственных карточек и один составной комплект
- 90 исследованных предложений конкурентов
- 62 предложения допущены в автоматическую очередь
- 28 предложений сохранены для проверки
- 23 модели позволяют сравнить свою и конкурентную цену
- 60 из 62 карточек успешно собраны в последнем полном задании
- отказ двух карточек одного сайта не остановил остальные источники

Последнее контрольное задание `a96f4466-8e50-4f67-8cbb-e9cb5fc6b959` завершилось с частичным успехом. Ошибки остались только у Топ Мастера для ROSSVIK V-26 и V-524. Повтор ограничен, Playwright не обходит CAPTCHA, прежние надёжные наблюдения не удаляются.

## Что требует решения руководителя

Для ES-26D, 4523PA1(B), Guangli GL2, GL3 LUX и GL10 нужны паспорта, фото шильдика или подтверждённая коммерческая спецификация. До этого найденные цены видны, но не участвуют в итоговом сравнении.

Нужно подтвердить правило для комплектов, когда продавец публикует части отдельно. Текущее безопасное правило складывает только подтверждённые части одного продавца. Также нужен контакт специалиста, который может подтвердить ошибочные или отсутствующие параметры собственного сайта.
