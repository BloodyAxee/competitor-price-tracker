## Быстрый запуск

1. Создайте локальный `.env` по примеру `.env.example` и задайте собственный пароль PostgreSQL.
2. Запустите Docker Desktop.
3. В корне репозитория выполните:

   ```powershell
   docker compose up -d --build
   ```

4. Откройте веб-интерфейс: <http://localhost:5173>

API доступен по адресу <http://localhost:3000>, проверка состояния — <http://localhost:3000/health>.

Остановить сервисы без удаления данных:

```powershell
docker compose stop
```

Посмотреть состояние контейнеров:

```powershell
docker compose ps
```

Проверить правила цен и отказоустойчивость сборщика в Python 3.13:

```powershell
docker run --rm -v "${PWD}/collector:/app" -w /app -e PYTHONPATH=/app/src python:3.13-slim python -m unittest discover -s tests -v
```

Проверить реальный Chromium и получение данных после выполнения JavaScript:

```powershell
docker compose run --rm collector python -m price_collector.playwright_smoke
```

Проверить запущенные API, веб-интерфейс, каталог, CSV, расписание и сохранённый запуск сбора:

```powershell
node tests/acceptance/api-smoke.mjs --job <UUID запуска>
```

## API сбора

- `POST /api/collection-jobs` — поставить ручной сбор в очередь. Тело `{"mode":"fast"}` запускает основные рабочие источники, `{"mode":"full"}` — все активные `exact`, `comparable` и `review`
- `GET /api/collection-jobs` — список запусков сбора и их статусы
- `GET /api/collection-jobs/:id` — попытки и ошибки конкретного запуска
- `GET /api/comparisons` — текущие надёжные цены и разница. Параметр `region=moscow` или код другой точки возвращает только цены этого региона
- `GET /api/regions` — семь основных региональных точек и число явно привязанных наблюдений
- `GET /api/products/:id/history` — append-only история товара
- `GET /api/export.csv` — UTF-8 CSV со всей историей цен конкурентов в стабильном формате
- `POST /api/manual-observations` — добавить проверенную ручную цену
- `GET /api/collection-schedule` — активное расписание и часовой пояс

## Что уже работает

- forward-only миграции и схема PostgreSQL 18
- идемпотентный импорт `modeli.csv` и `modeli-dop.csv`
- 267 товаров, включая 29 основных моделей, компоненты комплекта и дополнительный каталог
- 28 собственных карточек и автоматический расчёт комплекта `NORDBERG 4641N + VT-64`
- 64 точных предложения, 4 отдельных сопоставимых рыночных ориентира и 23 исследованных кандидата со статусом проверки
- региональные срезы Москвы, Санкт-Петербурга, Казани, Екатеринбурга, Краснодара, Новосибирска и Хабаровска без смешивания цен разных точек
- точные резервные источники для защищённых и нестабильных страниц
- API каталога и сводной статистики
- адаптивный веб-интерфейс с поиском и четырьмя понятными фильтрами, приоритетом строк с отличающейся ценой, разницей под ценой конкурента, отдельным анализом похожих моделей и историей изменения цены
- каркас Python-сборщика с очередью PostgreSQL, ограниченными повторами, изоляцией ошибок, circuit breaker после двух одинаковых сбоев домена и cooldown нестабильных резервных карточек
- HTTP- и браузерные адаптеры с проверкой точной модели, критичных характеристик и видимой цены
- браузерный fallback для сетевых ошибок и защищённых ответов, один контролируемый повтор для настроенных доменов и сохранение состояния браузерной сессии
- запрос пройти проверку человеком и внести цену вручную, если автоматическая попытка не сняла защиту
- API запусков сбора, текущего сравнения, append-only истории и проверенного ручного ввода
- CSV-выгрузка со стабильными столбцами, ручным методом и пометкой надёжности
- ежедневный полный сбор по `COLLECTION_CRON` в часовом поясе `APP_TIMEZONE` без дублей за день

После контрольного запуска хотя бы одна надёжная цена доступна для всех 29 основных моделей. Для 24 моделей доступны одновременно собственная и точная конкурентная цены. Для ES-26D, Guangli GL2, GL3 LUX и GL10 отдельно показываются цена сопоставимого рыночного ориентира, разница с ЦТО и раскрываемая таблица существенных характеристик. Эти ориентиры не подмешиваются в строгий итог. Региональная панель намеренно показывает отсутствие данных, пока регион не подтверждён источником или ручным доказательством. Из веб-интерфейса можно запустить полный сбор, открыть append-only историю модели и выгрузить CSV.
